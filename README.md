## About Me

- 🔭 R&D Intern @ Walchand College of Engineering — building **AgenticEval**, a six-agent AI system that auto-grades handwritten answer sheets (~10 min → <1 min per sheet)
- 🧠 Designed explainable, confidence-scored grading with a teacher review-and-approve workflow and full agent audit trails
- 🏗️ Built a SQLite-style **SQL database engine from scratch in C++** — tokenizer, parser, B-Tree indexing, 1000+ queries
- ⚡ Researching a faster pipeline to cut per-sheet latency ~60%, migrating orchestration to **LangChain**
- 🏆 3★ CodeChef · Finalist @ OFFGRID 1.0 Hackathon · Shortlisted @ MSME for AgenticEval
- 🎤 General Secretary, Social Media Club @ WCE — leading a team of ~30
- 🎓 B.Tech CSE, Walchand College of Engineering (2024 – 2028)
